# Instrucciones de ejecución

1. Instala o verifica que Apache Spark y Java estén configurados.
2. Revisa que `datos/ventas.csv` exista.
3. Abre una terminal en la carpeta `tarea3_procesamiento_spark`.
4. Ejecuta:

   ```bash
   spark-submit procesamiento_batch.py
   ```

5. Revisa la salida de la terminal.
6. Para trabajar con un conjunto de datos real, descarga el CSV desde una fuente pública confiable, guárdalo en `datos/`, actualiza la ruta en `procesamiento_batch.py` y adapta los nombres de las columnas si es necesario.
7. No subas contraseñas, credenciales ni archivos privados al repositorio.
